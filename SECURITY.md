# Security policy

## Supported versions

Security fixes are made on the current default branch. This project does not currently maintain separate release branches.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's **Security → Report a vulnerability** private reporting feature for this repository. If private reporting is unavailable, contact the repository owner through their GitHub profile and request a private reporting channel.

Include reproduction steps, affected revision, impact, and any suggested mitigation. Do not include Hugging Face tokens, model files, private prompts, or other credentials.

The downloaded models and `stable-diffusion.cpp` are third-party components. Vulnerabilities in those projects should also be reported to their respective maintainers.
